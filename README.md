## Minha contribuição

Este projeto foi desenvolvido como atividade acadêmica da disciplina de Desenvolvimento Backend, a partir de um repositório-base disponibilizado pelo professor.

Minha principal contribuição foi a criação e organização dos DTOs (Data Transfer Objects), utilizados para transportar dados entre as camadas da aplicação sem expor diretamente as entidades internas.

Essa estrutura ajuda a separar responsabilidades, organizar melhor os dados de entrada e saída da API e deixar o backend mais limpo e fácil de manter.
